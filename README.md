# blackjack
Computer version of blackjack card game. 

Features
- Creates multiple rounds by asking user if they want to play Blackjack after each round
- Gives the user and the computer a random set of cards
- Asks the user if they want to draw another card
- If they draw another card and the sum of their cards is above 21, they lose.
- If they draw another card and the sum of their cards is less than 21 and the computer's sum is above 21, they win.
- If the computer's sum is less than 21 and the user's sum is greater than 21, the computer wins.
- If either party's sum is 21, they automatically win.
